# srb

Карточки для повторения сербских слов. Без аккаунта и сервера: словарь лежит в приложении, статистика — в `localStorage` этого браузера.

Открыли страницу — сразу карточка. В колоде сначала 20 слов. Слово закрепляется, когда верных ответов уже два и их больше, чем ошибок. Каждое такое слово сразу пускает в колоду следующее, пока незакреплённых около четырнадцати: новые слова приходят по ходу, а не после всей пачки. Слово, которое долго не даётся, перестаёт держать очередь после шести показов. Слово, в котором уже ошибались, остаётся в колоде, даже если очередь до него ещё не дошла. Внутри колоды ошибки возвращают слово чаще, верные ответы — реже, но выученное слово не исчезает совсем. Только что показанное слово не выпадает следующим. Три карточки подряд просят перевести с русского на сербский, четвёртая — с сербского на русский.

Страница «Слова» — весь словарь. Сверху то, что запоминается хуже. Есть поиск по сербскому, транскрипции и русскому переводу.

## Локально

Откройте `index.html` через любой статический сервер. Модули не работают по `file://`.

```bash
python3 -m http.server 4173
```

## GitHub Pages

В настройках репозитория: Pages → Deploy from a branch → ветка `main`, папка `/ (root)`.

Адрес будет вида `https://<user>.github.io/<repo>/`. Пути в приложении относительные, отдельная сборка не нужна.

## Словарь

Источник — `data/dictionary.csv`. В транскрипции ударная гласная написана заглавной: данас → дАнас, јуче → Юче. Клитики, предлоги и союзы внутри фразы без ударения; «ne» перед словом с ударением на первом слоге забирает его себе (нЕ идем).

Индексы ударения лежат в `data/stress.json`. После правки словаря:

```bash
python3 scripts/build-dictionary.py
```
